# Liste de course

Appli web installable (PWA) pour faire ses courses, utilisable **hors ligne** sur Android.

- Liste à cocher : produits de base, ajouts personnels, ingrédients des recettes
- Barre de recherche : chercher un produit ou l'ajouter, avec sa catégorie
- Mode magasin : cocher ce qui est dans le panier, rangé par rayon
- Carnet de recettes avec calcul des quantités selon le nombre de couverts
- Import des recettes depuis la page Claude (code `LDC1:`)

Les données restent sur le téléphone (stockage du navigateur).

## Installation

1. Ouvrir https://tuce-hub.github.io/Liste-de-course/ dans Chrome (Android).
2. Menu ⋮ → **Installer l'application**.
3. « Hey Google, ouvre Liste de course ».
